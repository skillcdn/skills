# Rules for design skills

These add to the rules of the repository.

**Match what exists.** New work in an existing file takes its type, colors, spacing and element specs from what is there, measured, and invents only what the file lacks.

**Check the render.** A visual result is judged on a render of it before it is shown, never on coordinates alone.
