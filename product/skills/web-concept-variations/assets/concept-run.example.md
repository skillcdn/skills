# The artifacts of a run, with placeholders

Five files in the run folder, in the order they are written. Angle brackets are placeholders; "none" is written where a reading, a reference or a fix is absent, so that the next reader sees what was looked for.

## effect-brief.md

```markdown
# Effect brief: <the reference, as the user named it>
Subject: <what the directions are for> · Audience: <who, which market, which language> · Medium: <of the piece, or open>
Read from: <the piece; its public description; the maker's account; analyses>, each cited by where it was seen.

| Reading | Sentence | Evidence |
|---|---|---|
| Intent | They wanted <who> to <do or feel what>. | <where read> |
| Effect | At <where in the piece> the viewer <what>; at <where> <what>. | |
| Aesthetics | <A choice> says <what it signals>; <a choice> says <what>. | |
| Fun | The device is <the concrete thing>, which <how it gives pleasure>. | |
| Expected effect | They expect <a click, a share, a save, a yes>. | |
| Prior knowledge | <a genre>, <a norm>, <a pain>; the audience has <which of them>. | |

Mechanism line: it works because <the effect> comes from <the device>, which rests on <the prior knowledge>, and the viewer is expected to <the expected effect>.
Stays: <the mechanism line; the medium; the register's level; the place of the turn>. Free: <situation, setting, cast, lines, device where another carries the rule>.

## Other references

|---|---|---|

```

## handoff.md

The effect brief, the pick's row, the mechanism line and the rule, what must stay, the sample, the fixes, the other references by where seen, the assumptions the run rests on (which piece was read, the market, the medium) and what was left out; then the producing skill's inputs, in its own vocabulary, filled as far as the pick fills them; what it will still ask.
