# Model selection and credit estimate

The ad is generated by the Kling or the Seedance family. The agent recommends one from a side-by-side estimate, the user confirms or picks the other, and a version is never pinned: the latest general model of each family is discovered at run time. The mechanics every Higgsfield skill shares (how the catalog is read, the lowest tier, the preflight and what it may answer instead of a number, `use_unlim`, one job per call, refused jobs, a higher resolution later) are in [/docs/higgsfield/models.md](/docs/higgsfield/models.md); this page is what the ad adds.

## Finding the latest model

```
models_explore  action: search  type: video  query: kling
models_explore  action: search  type: video  query: seedance
```

From each result, pick the latest general model of the family as the shared page says, able to produce 9:16 and native audio when the brief has spoken lines, and read its parameters with `action: get`: the duration range or options, how quality is selected, and its roles (a start frame, an identity reference).

## Tier and audio

Lock the lowest tier the shared page's table gives (`480p`, else `std`, a draft flag where there is one), for both families. Native audio on for shots with dialogue or diegetic sound, off for shots that get music in the edit; whether off is cheaper, the preflight tells. Drafts are what the user pays for: a higher resolution (the finalize of the accepted takes where the draft tier offers one, quoted; an upscale of the master, which has no preflight) is a separate step offered at the delivery and started only on the user's word.

**Animated looks.** Both families animate a drawn first frame; no style parameter is needed, the frame and the style line in the prompt set the look. A catalog entry that says the model holds stylized or anime looks steady decides a tie.

## Preflight

Once per family, distinct duration and audio setting of the shot list for the takes, and once per image model and setting for portraits and frames ([cast.md](cast.md)); before the user sees the plan (phase 4), once the shot list fixes the durations, and again for any shot the user changes. A preset recommendation instead of a number is answered with the same call plus `declined_preset_id` set to that preset's id, passed again on the real generation. A reference-mode model that needs an image even to quote is preflighted with the product image's media id. Reserve: one extra take per three shots (rounded up), priced at the most expensive shots; one extra portrait per cast member; one extra frame per three shots. Read `balance`.

## The estimate

```
Family     Model      Tier   Video per shot        Images                              Reserve             Total
Kling      <latest>   std    10, 10, 20, 10 = 50   2 portraits 2 + 4 first frames 8    +20 video, +4 img   84
Seedance   <latest>   480p   15, 15, 30, 15 = 75   2 portraits 2 + 4 first frames 8    +30 video, +4 img   119
Balance: <credits> · Free-trial unlimited generations: <available or not>
```

The numbers are illustrative, shaped like preflights for 5- and 10-second 9:16 shots with audio and 1k images; they are not current prices. Present only numbers that came back from `get_cost` in this run.

The table is for the agent. The user sees, in plain words, the recommended family with its total including the reserve, the balance, and the other family's total in one line. Recommend by these, in order, and give the reason in one line: the family whose video model takes both a start frame and the portrait as an identity reference (a steadier cast across shots); the lower total; the durations the shot list needs; native audio in the dialogue language. Name the **fallback** in the same breath: a role list is not proof that the frame and the portrait combine in one call, so when the first take refuses them together, the ad goes on with the other family at its quoted total, or with the same model and the portrait alone as its reference and the frame's composition described in the prompt; when the user's word covered it, the switch happens without a second stop, and the images already made are kept. Then ask for one word to proceed, or the other family, or a change to the plan. The answer stands for the rest of the run. If the user later asks for more shots or more retries, re-quote first. Free-trial unlimited generations are offered, and `use_unlim` set, as the shared page says.
